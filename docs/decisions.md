# Decisions and Open Questions

This is the single place for unresolved questions and settled decisions, for all the design docs. Answer open questions inline. When one is settled, move it to the decision log and update the doc it affects.

## Open questions

1. **Population and ecosystem health** (features). Population dynamics are linked to a simulation of ecosystem health, and generation-ship ecosystem failure is a failure state. What does ecosystem health measure (for example: biomass, nutrient-cycle balance, atmosphere quality, genetic diversity)? What degrades and restores it? How does it drive population growth or decline?

> TBD.

2. **Propulsion resource gates** (features). The engine types are now set (decision 19). Which resources gate each type, and in what order are they unlocked? Are solar-electric propulsion and realistic low-thrust fusion (decision 8) still in the list, as "other current or future technologies"?

> Yes, solar-electric and realistic low-thrust fusion can be added to the engine types.

3. **Construction in milestone 2 vs. milestone 4** (milestones). Milestone 2 now includes "ship design and construction", and milestone 4 still lists "construction, stations and habitats". Is the split ship construction (at the generation ship) in milestone 2, and station and habitat construction in milestone 4?

> Yes, basic ship design and construction is introduced in milestone 2.

4. **Station control** (interface). Should stations be edited through the inspector at any time (recommended), or use an "active station" model like ships? _TBD._

5. **Flows visualisation** (interface). Should resource flows be drawn on the map (route lines sized by throughput), on a diagram in the Economy screen, or both? _TBD._

6. **Content and units** (sprint 0). Should `content/` be allowed to import `math/units.ts`? For now content imports nothing. Units are the likely reason to relax this, so content could write values in convenient units (for example `mass: toKg(2.3, 't')`) or use `G0`. The narrow change would be to allow `content → math/units.ts` only, which is safe because `units.ts` has no imports. _TBD._

7. **Textbook test values** (sprint 1). The textbook cases in `orbital/*.test.ts` (Vallado, 4th ed.; Curtis, 3rd ed.) were written from memory, not copied from the books. All but one pass; Curtis 3.4's radius didn't match and was dropped, and Curtis 3.7's last velocity digit differs. Check them against the books. _TBD._

8. **Saturnian moons and Triton** (sprint 1). JPL's current satellite rows for these disagree with Horizons by up to 157° at their own epoch, while the archived 2020 rows of the same table agree. They are kept as given (decision 71). Should the 2020 rows be used instead, if the phases ever matter in play? _TBD._

9. **Ships hidden by their parent** (sprint 3). A refocus keeps the camera's direction, so a focused ship on the far side of its parent is hidden behind the parent's disc (the smoke test snaps to the ship's orbit first). Should focusing a ship choose a viewpoint where its parent doesn't hide it, for example from above its orbit plane? _TBD._
